**Added (ledger file):** `.analysant/ledger.jsonl` now begins with a format header, `{"type":"format","name":"analysant-ledger","version":1}` (`ledger_file::LEDGER_FORMAT_VERSION`). `render` writes it first; `parse` requires it on a non-empty file and refuses a missing header (`MissingHeader`) or any other version, older or newer (`UnsupportedVersion`, naming both); it is never an event (no id, absent from `state` and `history`); the new `merge_text` merges two files, keeps one header and is byte-identical in either order, and refuses files of different versions (`VersionMismatch`). A ledger file written before this change has no header and is refused (none exists outside tests). Version is PM-allocated.
