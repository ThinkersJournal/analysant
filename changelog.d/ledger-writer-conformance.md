**Added:** a ledger-writer conformance kit for tools that write `.analysant/ledger.jsonl` (EditAnt): two golden files (`canonical.jsonl`, `escaping.jsonl`), a reference writer (`cargo run -p analysant-core --example ledger_writer [escaping]`), 13 tests (`analysant-core/tests/ledger_conformance.rs`, `ledger_extraction.rs`), an independent Python checker, and the rules in `docs/LEDGER-WRITER-CONFORMANCE.md` (event-id computation, JSON escaping, revisions, locking and whole-file rewrite, section moves, CRLF).
**Changed:** `corpus` (`extract_document`, `extract_corpus`, `Corpus`, `Document`) and `ledger_file` moved from `analysant` into `analysant-core` so a writing tool needs only the core crate; `analysant::corpus` and `analysant::ledger_file` re-export them, every existing path works (test `reexports.rs`), and `analysant-core` now depends on `serde` and `serde_json`. Core's scope grew with this (the PM's core-only publish ruling was read before the move). `mint_key` is now public. No behaviour or id changed.
