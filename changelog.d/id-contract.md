**Documented (analysant-core):** the unit id contract. `analysant_core::content_id` returns an *identity*, not an integrity check: two 64-bit FNV-1a hashes in a `u128`, not cryptographic; collisions are possible and can be constructed on purpose, and no claim is made against an adversary. Its output is stable (pinned by `content_id_stability_vector`; changing it is a Breaking release). The rest of `analysant-core`'s API may change in any 0.n minor release.
