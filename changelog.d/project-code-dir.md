**Added:** `[code] dir = "..."` in `.analysant/project.toml` names the git work tree the doc-vs-code lens reads (relative to the project root), so `analysant findings|counts <dir>` no longer needs `--code`. `--code` on the command line overrides it. A listed directory that does not exist or is not a git work tree is an error naming the key and the path, never a silent skip; `dirs` or any other key under `[code]` is an unknown key and an error. With neither the key nor the flag, every output is byte-identical to before.
