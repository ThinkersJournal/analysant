**Changed (breaking for recorded ids):** every unit id and every claim-derived finding id changed. There is now one content-based id scheme for every unit kind, `analysant_core::content_id` (unit kind, document, section path, text, occurrence, generation); the in-memory ledger's salt and counter are gone, so the same content gets the same id in any ledger, run, branch or mint order, and `identity::mint_id` is the same function. The CLI's golden finding lines were regenerated in the same commit (the contradiction finding id, computed from `file:line` pairs, is unchanged). `Ledger::with_salt` is removed. The ledger writer is recorded in the spec as EditAnt's (D5), with its required interface; AnalysAnt does not write the ledger. Version is PM-allocated.
