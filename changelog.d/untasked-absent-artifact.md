### Added
- `[untasked] absent_artifact = true`: the narrow check (Gate B round 5). A finding is an unticked box in a live document (no superseded/obsolete/complete/done marker in its heading or first lines, outside the non-work documents) whose step names an artifact absent from the tree at the checked-out revision: a file path (neither the path nor its file name is tracked) or a backticked symbol (no tracked non-markdown file contains it). Commands are not checked. Off by default, so the Gate A oracle is unchanged. An open item in a superseded or completed document is not a finding. Recall is not measured.
